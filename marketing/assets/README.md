- `12-first-version.png`.

## Технические требования

- соотношение сторон: 16:9 либо запас под обрезку;
- минимальный размер: 1920×1080;
- без текста внутри изображения — текст добавляется в презентации;
- единая палитра и один повторяющийся мотив живой линии;
- сохранять исходники отдельно от финальных PNG/JPEG;
- не использовать изображения с неясной лицензией.

## Безопасность детей

- не публиковать лица, имена, школу, геолокацию и интерьер дома без отдельного согласия;
- дочери дать право отдельно согласовать каждое публичное изображение её работы;
- для публичной версии предпочитать руки, силуэты, фрагменты процесса, макеты или иллюстрации;
- работы детей подписывать только с их согласия;
- генеративные изображения не выдавать за реальные результаты семейной программы.
