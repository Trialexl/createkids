# CreateKids web app

Интерактивная 12-недельная семейная программа с локальным режимом, семейными аккаунтами, синхронизацией прогресса и приватной по умолчанию галереей работ.

## Требования

- Node.js 22.12 или новее (`node:sqlite` входит в Node.js);
- npm 10 или новее.

## Локальная разработка

```bash
npm install
npm run dev
```

Интерфейс откроется на `http://127.0.0.1:5173`, API — на `http://127.0.0.1:4174`. Vite проксирует запросы `/api` на сервер приложения.

## Проверка

```bash
npm test
npm run build
```

## Production-запуск

```bash
npm run build
npm start
```

По умолчанию сервер слушает `127.0.0.1:4174`. Поддерживаемые переменные окружения:

- `HOST` — адрес привязки сервера;
- `PORT` — порт;
- `DATA_DIR` — каталог SQLite-базы и загруженных фотографий;
- `COOKIE_SECURE=false` — разрешить сессионную cookie по HTTP только для локальной проверки production-сборки.

В обычном production-окружении приложение следует публиковать через HTTPS reverse proxy. Безопасная cookie включается автоматически при `NODE_ENV=production`.

Данные находятся в `DATA_DIR`: база `createkids.sqlite` и каталог `uploads/`. Для резервной копии нужно сохранять оба объекта вместе. Каталог `data/` исключён из Git.
