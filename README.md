# CreateKids — семейная лаборатория творчества

## Цель проекта

Создать устойчивую семейную практику, в которой дети **пробуют разные способы создавать новое**, замечают собственные интересы и постепенно выбирают направления для углубления.

- Дочь: 14 лет
- Сын: 7 лет
- Горизонт первого пилота: 12 недель
- Формат: отдельные возрастные задания + совместные семейные проекты

## Главный принцип

Цель — не вырастить «универсального художника» и не заполнить расписание кружками. Цель — регулярно тренировать творческий цикл:

> заметить → собрать влияния → разобрать приёмы → придумать варианты → выбрать → сделать первую версию → изменить → улучшить → назвать источники → показать или сохранить

В программу встроены практики из книги Остина Клеона «Кради как художник»: копилка вдохновения, изучение нескольких влияний, учебное подражание с последующей трансформацией, работа руками, побочные проекты, ограничения и показ процесса. Это не разрешение на плагиат: ребёнок учится отличать источник, учебную копию и собственное авторское решение.

## Критерии успеха пилота

- [ ] Каждый ребёнок попробовал не менее шести разных творческих направлений.
- [ ] У каждого появилось 1–2 направления, к которым он сам хочет возвращаться.
- [ ] Семья провела не менее восьми совместных творческих сессий.
- [ ] У каждого ребёнка есть портфолио процесса: идеи, черновики, фото, записи и законченные работы.
- [ ] Каждый ребёнок умеет назвать хотя бы несколько источников вдохновения и объяснить, что он изменил в собственной работе.
- [ ] Занятия не стали постоянным источником конфликтов или перегрузки.
- [ ] Решение об углублении принято по наблюдаемому интересу ребёнка, а не по сравнению с другими.

## Что не использовать как главный показатель

- «Красивость» результата.
- Количество лайков, конкурсов и грамот.
- Сравнение детей между собой.
- Скорость освоения техники.
- Соответствие работе взрослого образца.
